### 추가

- **구매발주** — 중단된 프로젝트 자동 재개: 실행 중 중단됐던 프로젝트를 다시 실행하면 이전에 처리하다 만 이동요청·구매요청을 스스로 이어서 처리합니다. 재개 대상이 있으면 실행 전 화면에 재개 안내 배너가 뜹니다.
- **구매발주** — 이전 계획서 찾기 개선: 저장 일자별로 묶어 보여주고, 프로젝트명·코드·WBS 로 검색할 수 있습니다.

### 개선

- **구매발주** — 계획서 확정 이후 저장→상신→발주 전 구간이 자동으로 진행됩니다(단계별 확인 개입 제거).
- **구매발주** — 상신·발주를 3개 세션이 병렬로 처리해 전체 소요가 줄었습니다. 화면 하단에 세션별 처리 현황이 표시됩니다.
- **구매발주** — 발주 화면 입력 속도 최적화: 고정 대기를 결과 확인 즉시 진행으로 바꾸고, 이미 발주된 건은 빠르게 건너뜁니다.
- **구매발주** — 계획서 비고 표기 개편: 기본 문구를 '직배송 {거래처명}'으로 통일하고, 거래처명은 법인 표기(주식회사 등)를 뗀 축약명으로 적습니다. 발주 패턴 예외 비고에 적힌 분류명(가공품·판금품)은 실제 거래처명으로 자동 치환됩니다.
- **구매발주** — 계획서 비고 입력칸을 1.5배 넓히고, 프로젝트 도움창 검색어를 프로젝트 코드로 바꿔 이름이 같은 프로젝트가 섞이지 않게 했습니다.
- **법인카드** — 실행 완료 화면 중앙에 '상신은 직접 진행해 주세요' 안내를 크게 표시합니다(기존 우측 결과 탭 안내가 작아 안 보이던 문제).

### 주요 수정

- **구매발주** — 자동 재개 경로의 내부 오류로 실행이 즉시 중단되던 문제를 수정했습니다.
- **구매발주** — 발주 팝업 조회에 다른 요청의 잔존 건이 섞이면 잘못된 행이 선택될 수 있던 문제 — 요청번호가 일치하는 행만 선택하고 나머지는 제외합니다.
- **구매발주** — 구매발주유형 입력 방식 문제로 구매요청 버튼이 눌리지 않던 문제를 수정했습니다.
- **구매발주** — 비고 입력 후 행 이동이 멈춰 진행이 정체되던 문제를 수정했습니다.
- **구매발주** — 재실행 시 상신→발주를 한 번의 실행으로 이어서 재개하지 못하던 문제를 수정했습니다.

### 수정

- **구매발주** — 실행 결과 요약이 화면 오류로 표시되지 않던 문제를 수정했습니다.
- **구매발주** — 병렬 처리 중 진행 타임라인이 뒤로 점프해 보이던 문제를 수정했습니다.
- **구매발주** — 계획서 검토와 이전 계획서의 발주단위 표 컬럼 폭을 통일해 표끼리 비교하기 쉽게 했습니다.
