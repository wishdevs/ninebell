### 추가

- **국내출장(자차)** — 출장 결의서 작성 에이전트
- **해외출장** — 출장 결의서 작성 에이전트
- **출장** — 실행 전 입력 폼 — 출장 정보를 미리 받아 진행
- **출장** — 상대계정 거래처 자동 등록, 공급가액 예산현황 확인
- **공통** — 거래처 카탈로그 동기화·관리 화면
- **공통** — 옴니솔 조직도 자동 동기화 + 부서별 기본 프로젝트
- **공통** — 에이전트 그룹 드릴인 화면과 실행 통계
- **공통** — 사외에서도 접속 가능하도록 서버 배포

### 개선

- **법인카드** — 전사 기초자료를 서버 시작 시 자동 적재
- **공통** — 개입이 필요하면 화면을 보고 있지 않아도 알림이 뜹니다.

### 주요 수정

- **공통** — 로그인이 되지 않던 문제 수정 (세션 쿠키 도메인)
- **법인카드** — 예산계정·프로젝트·적요가 비어 있으면 저장을 막도록 검증 추가
- **공통** — 프로젝트 카탈로그 동기화가 0건으로 끝나던 문제 수정

### 수정

- **공통** — 알림 배너가 반복해서 뜨지 않던 문제
