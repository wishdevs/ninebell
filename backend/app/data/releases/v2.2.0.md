### 추가

- **출장(국내/자차)·출장(해외/정산서)·경조금·학자금** — 그동안 검증 중이라 일부에게만 보이던 4종을 모든 사용자에게 공개했습니다. 결의서입력 그룹에서 바로 실행할 수 있습니다.

### 개선

- **법인카드** — 주소가 업무 이름과 맞도록 `/agents/card-chat` 에서 `/agents/corporate-card` 로 바뀌었습니다. 화면 이름·실행 이력·세부설정(회계시점 결정일)·조직구분 접근 권한은 그대로이고, 홈의 자주쓰는 에이전트도 자동으로 옮겨집니다. 예전 주소를 북마크해 두었다면 다시 저장해 주세요.
- **세금계산서** — 질문 화면이 가장 흔한 조합(발행 후 · 비용분할 안 함 · 과세 = 증빙유형 **03 세금계산서**)으로 미리 채워진 채 열립니다. 다른 건이면 해당 줄만 눌러 바꾸면 되고, 증빙유형 코드에서 바로 고르는 방식도 그대로 쓸 수 있습니다.

### 수정

- **공통** — 에이전트 상세 화면 위쪽에 있던 두 번째 **실행** 버튼을 없앴습니다. 실행 시작점이 화면 가운데 버튼(실행 전 입력이 필요한 에이전트는 그 입력 폼) 하나로 정리돼, 회계전표처럼 폼이 있는 화면에서 눌리지 않는 실행 버튼이 함께 보이던 혼란이 없어졌습니다.
- **공통** — 로그인 화면의 **디버그 모드** 선택을 실제 사용 환경에서는 감췄습니다. 개발·테스트 환경에서만 보입니다.
