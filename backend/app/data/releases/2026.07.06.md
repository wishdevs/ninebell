### 추가

- **공통** — 홈 대시보드 — 실행 현황 요약, 최근 실행 이력, 자주쓰는 에이전트 바로 실행
- **공통** — 에이전트 즐겨찾기(★)
- **공통** — 실행 예상 시간 타임라인 — 단계별 소요 시간을 실제 실행 기록으로 예고
- **공통** — 개입이 필요할 때 브라우저 알림·탭 제목으로 알려줍니다.
- **공통** — 에이전트를 문서군(결의서 작성 등)으로 묶는 2단계 그룹
- **공통** — 에이전트별 세부설정 화면 (관리자)
- **공통** — 완료 후 다음 할 일 안내 (법인카드는 저장 후 결제 상신)
- **법인카드** — 적요 일괄 입력, 값 출처 배지, 오류 행 바로가기
- **법인카드** — 예산단위 검색형 선택 상자
- **개입 학습** — 개인 학습 데이터 삭제 (행별/전체)

### 개선

- **공통** — 워크플로우 화면을 단계 레일 + 세부 펼치기 구조로 개편
- **공통** — AI가 하는 작업을 별도로 표시하고, 개입 대기를 눈에 띄게 표시
- **법인카드** — 사용자가 실제로 바꾼 항목만 학습 (미리 채운 값을 그대로 두면 학습하지 않음)
- **법인카드** — 저장에 실패하면 왜·어느 행·어떻게 고칠지 안내하고 해당 행을 강조
- **법인카드** — 조회 0건이면 '처리할 내역이 없습니다'로 즉시 종료

### 주요 수정

- **개입 학습** — 학습 내용이 한 건도 저장되지 않던 문제 수정
- **개입 학습** — 수정 표시가 중간에 사라져 학습이 누락되던 문제 수정

### 수정

- **공통** — 열자마자 '개입 필요·진행 중'으로 잘못 보이던 문제
- **공통** — 실행 상태 배지가 화면마다 다르게 보이던 문제
- **공통** — 로그인·회원가입 화면의 제목 중복
- **공통** — 결과 탭에서 다음 할 일 안내가 아래쪽에 묻히던 문제

### 변경

- **법인카드** — 개입 제출이 2단계 확인에서 1클릭으로 돌아왔습니다.
- **공통** — 예산단위·프로젝트 관리가 사이드바에서 '결의서 작성' 그룹 안으로 이동했습니다.
