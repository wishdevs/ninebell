법인카드 에이전트가 처음으로 옴니솔에 **실제 저장까지 성공**한 릴리스입니다.

### 추가

- **공통** — 조직구분 관리 + 조직별 에이전트 사용 권한
- **공통** — 자주쓰는 예산단위·프로젝트 지정과 ERP 코드 카탈로그 동기화
- **공통** — AI 어시스턴트
- **공통** — 개인 계정 설정 화면
- **법인카드** — 표 형태 개입 화면 — 예산단위·프로젝트·적요를 직접 확인하고 고칠 수 있습니다.
- **법인카드** — 부가세구분에 따라 과세/불공 2회로 나눠 증빙을 입력
- **법인카드** — 예산단위 선택지를 자주쓰는 항목과 내 부서로 한정

### 개선

- **공통** — 감사·로깅 목록에 번호형 페이지 이동

### 주요 수정

- **법인카드** — 저장되지 않았는데 성공으로 보고되던 문제 수정 (실제 저장 경로 구현)
- **법인카드** — 저장 중 오류 창이 떠도 성공으로 처리되던 문제 수정
- **법인카드** — 증빙 2차 입력이 기존 행을 덮어쓰던 사고 수정
- **법인카드** — 2차 적용 성공을 실패로 잘못 판정하던 문제 수정
- **법인카드** — 개입 중 입력한 내용이 사라지던 문제 수정
- **공통** — 계정 화면이 흰 화면으로 죽던 문제 수정
- **공통** — 예산단위를 '내 부서' 기준으로 잘못 걸러내던 문제 수정

### 수정

- **공통** — 목록에서 페이지를 옮길 때 스크롤이 위로 돌아오지 않던 문제
- **AI 어시스턴트** — 답변 영역이 화면 폭을 다 쓰지 않던 문제
- **법인카드** — 조회 결과가 0건일 때 아무 안내 없이 끝나던 문제

### 보안·개인정보

- **공통** — 로그인 시도 횟수 제한
- **공통** — 로그아웃·재로그인 시 이전 세션 즉시 무효화
- **공통** — 조직 접근 권한이 없는 사용자에게는 에이전트 목록·상세를 숨김
