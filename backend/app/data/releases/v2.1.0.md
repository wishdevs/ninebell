### 추가

- **세금계산서** — 결의서입력 그룹에 세금계산서 화면이 새로 생겼습니다. 발행 전/후 → 계산서일 기간 → 비용분할 → 과세·비과세·불공을 차례로 답하면 증빙유형 코드가 자동으로 정해지고, 발행 후에는 목록에서 대상을 골라 최대 20행까지 비용을 나눌 수 있습니다(취소분 같은 음수 금액도 지원). 아직 화면 흐름을 확인하는 단계라 옴니솔에 실제로 입력하지는 않습니다.
- **메뉴얼** — 사이드바에 **메뉴얼** 메뉴가 생겼습니다. 왼쪽 분류에서 문서를 고르면 실제 화면 스크린샷과 함께 사용법을 볼 수 있고(일반 2건·결의서입력 6건·회계전표 3건, 총 11문서), 문서마다 고유 주소가 있어 링크로 공유할 수 있습니다. 에이전트 상세 화면의 **메뉴얼** 링크로도 바로 들어갑니다.

### 개선

- **외상매출금·외상매입금·미지급금 법인카드** — 결제창에서 실제로 **상신**(결재 올리기)까지 진행합니다. 종전에는 결재창을 열어 확인만 했습니다. 상신에 실패하면 실행을 즉시 중단하며, **보관** 버튼은 누르지 않습니다. 잘못 상신한 건은 전자결재의 상신문서에서 결재취소로 되돌릴 수 있습니다.
- **미지급금 법인카드** — 결제창에서 참조문서를 검색해 첨부하고 **확인**까지 누릅니다. 참조문서 1건이 붙은 것이 확인돼야 그 결재 건을 완료로 처리하며, 첨부된 내용을 실행 화면에서 눈으로 볼 수 있습니다. 조회 결과에 결의서번호를 가진 내역이 하나도 없으면 불필요한 수집을 건너뛰고 바로 끝냅니다.
- **외상매입금** — 외상매출금과 같은 기준으로 묶음 결재를 합니다. 하위 항목이 200건 이상인 전표는 단독으로 먼저, 나머지는 합계가 200건 미만이 되도록 묶어 묶음당 결재창을 한 번만 엽니다.
- **법인카드** — 같은 가맹점·같은 시간대 내역을 한 묶음으로 보고 대표 1건만 AI가 판단한 뒤 묶음 전체에 적용합니다. 금액이 크게 튀는 건은 따로 판단하고, 승인취소 내역은 원거래와 같은 계정으로 맞춰 옴니솔이 "승인 건 계정과 다릅니다"로 저장을 거부하던 경우를 미리 막습니다.
- **법인카드** — 카드 조회 시 본인 명의 카드를 선택합니다. 본인 명의 카드가 한 장도 없는 계정이면 전체를 후보로 담고 그 사유를 안내하므로, 처리할 내역은 다음 단계 표에서 직접 확인·선택하면 됩니다.
- **법인카드** — 회사 직급 체계를 반영해 팀원에게는 접대비·회식비를 추천하지 않습니다. 승인시각이 `00:00`으로 넘어온 내역은 자정 결제로 오해하지 않습니다.
- **세금계산서** — 질문을 한 번에 하나씩 보여주고, 답한 내용은 왼쪽에 쌓아 **수정**으로 언제든 되돌아갈 수 있습니다. 계산서일 기간은 이번 달·한 달 전·두 달 전 버튼으로 한 번에 넣을 수 있고, 자주 쓰는 선택지는 바로선택으로 묶었습니다. 지금 답이 어떤 증빙유형 코드가 되는지 화면에서 실시간으로 보입니다.
- **세금계산서** — 글자가 작아 읽기 어렵던 화면을 다시 설계했습니다. 질문·선택지·증빙유형 코드를 키우고, 작은 버튼과 체크박스를 누르기 쉬운 크기로 넓혔습니다. 비율로 나눌 때 생기는 1원 단위 잔돈은 마지막 행이 흡수해 남은 금액이 정확히 0이 됩니다.
- **공통** — 화면이 준비될 때까지 고정 시간을 기다리던 방식을 상태 확인 방식으로 바꿔 실행이 건당 4~12초 빨라졌고, 옴니솔이 느린 날에는 대기 시간이 자동으로 늘어나 시간 초과로 실패하던 경우가 줄었습니다.
- **공통** — 에이전트 목록과 실행 목록 조회가 빨라졌습니다. 실행 기록이 쌓여도 목록이 느려지지 않습니다.
- **공통** — 저장이 확정되는 구간에서는 중지를 눌러도 저장 결과(저장됨·거부·실패)를 확인한 뒤 종료합니다. 반쯤 저장된 채 끊기지 않습니다.
- **공통** — 실행이 끝난 뒤에도 화면이 잠시 유지돼 마지막 상태를 볼 수 있습니다.
- **출장(국내/자차)** — 빈 행 삭제가 첫 클릭에 처리되면서 전체 실행 시간이 약 16% 짧아졌습니다.

### 주요 수정

- **공통** — 옴니솔 사용자유형 목록이 바뀌면서 로그인 후 회계 사용자로 전환하는 단계가 실패해 모든 에이전트가 시작조차 못 하던 문제를 고쳤습니다. 앞으로 유형이 더 늘어도 실제 목록을 읽어 처리합니다.
- **외상매출금·외상매입금·미지급금 법인카드** — 조회 조건(기간·작성부서·전자결재상태·전표유형)이 간헐적으로 반영되지 않아 실행 4건 중 1건꼴로 실패하던 문제를 고쳤습니다. 값을 넣은 뒤 반드시 다시 읽어 확인하고 어긋나면 다시 넣으며, 조회 버튼이 눌리지 않았는데 "0건 정상 완료"로 끝나던 경우도 없어졌습니다.
- **외상매입금** — 조회 건수가 많을 때 "체크된 행 수가 1이 아닙니다"로 중단되던 문제를 고쳤습니다.
- **미지급금 법인카드** — 수집 범위를 정하는 값(결의자·회계일)이 화면에 반영되지 않았는데도 계속 진행해 엉뚱한 범위로 수집하던 문제를 고쳤습니다. 확인될 때까지 다시 넣고, 그래도 반영되지 않으면 실행을 멈춥니다.
- **미지급금 법인카드** — 참조문서를 검색해 놓고도 아래로 이동이 되지 않아 첨부 없이 넘어가던 문제를 고쳤습니다. 대상 문서를 찾은 뒤의 실패는 성공으로 묻지 않고 실행을 중단합니다.
- **출장(국내/자차)·출장(해외/정산서)·경조금** — 예산현황 확인 창이 닫히지 않아 실행이 실패하던 문제를 고쳤습니다.
- **출장(국내/자차)** — 빈 행 삭제 클릭이 화면 상단 겹침 영역에 먹혀 실제로는 눌리지 않던 문제를 고쳤습니다. 확인 창을 놓쳐 빈 행이 남은 채 저장되던 문제도 함께 해결했습니다.
- **출장(해외/정산서)** — 이름이 같은 프로젝트 중 다른 항목이 저장되던 문제, 거래처 항목이 있는데 "항목 없음"으로 판단해 등록 없이 저장되던 문제를 고쳤습니다.
- **경조금·학자금** — 증빙·증빙유형·거래처·프로젝트 입력이 반영됐는지 확인되지 않았는데도 조용히 "완료"로 기록되던 문제를 고쳤습니다.
- **법인카드** — 저장 후 재조회가 실제로 실행되지 않았는데도 저장된 것으로 판단하던 문제를 고쳤습니다.
- **법인카드** — 목록이 스크롤된 상태에서 상세 행을 고르면 엉뚱한 행이 선택되던 문제를 고쳤습니다.
- **법인카드** — 개입으로 고친 내용이 동시에 저장될 때 학습 결과가 통째로 사라지던 문제를 고쳤습니다.
- **공통** — 코드 검색창에 조건이 들어가지 않은 채 전체 목록에서 잘못 고를 수 있던 문제를 고쳤습니다. 증빙 팝업이 닫히지 않은 채 남아 다음 행을 오염시키던 경로도 막았습니다.
- **공통** — 화면 진입 중 페이지가 죽으면 그대로 실패하던 것을 한 번 자동으로 복구합니다.

### 수정

- **에이전트** — 목록·상세에서 실행횟수와 평균 소요시간이 항상 0으로 보이던 문제를 고쳤습니다. 실행이 끝나면 즉시 반영됩니다.
- **멤버** — 조직구분 선택에서 3단계 아래 팀(회계팀 등)이 공백으로 보이던 문제를 고쳤습니다. 목록·상세·일괄 변경·필터 네 곳에 모두 적용됩니다.
- **공통** — 화면 일부에서 오류가 나도 전체가 빈 화면으로 죽지 않고 해당 영역만 오류로 표시됩니다.
- **공통** — 옴니솔 점검 등으로 로그인 화면 자체가 열리지 않을 때 비밀번호 오류로 처리돼 계정이 잠기던 문제를 고쳤습니다.

### 변경

- **공통** — 실행이 20분(사용자 응답을 기다리는 시간은 제외)을 넘으면 마지막 화면을 남기고 자동으로 정리하며 중단합니다.
- **공통** — 사이드바의 **변경사항**·**개발** 메뉴와 홈 화면의 푸시 알람 테스트는 로그인 시 디버그 모드를 켰을 때만 보입니다.

### 보안·개인정보

- **공통** — 로그인 화면에 들어 있던 테스트 계정 정보를 제거했습니다.
- **공통** — 다른 사람 권한으로 위조한 접속 토큰을 걸러냅니다. 운영 환경이 기본 비밀키로 기동하면 아예 시작되지 않도록 막았습니다.
- **공통** — 사내 프록시를 거친 접속이 모두 한 사람으로 묶여 접속 제한에 걸리던 문제를 고쳤습니다.
- **공통** — 관리자 화면 중 아직 준비되지 않은 견본 화면은 운영 환경에서 열리지 않습니다.
