### 추가

- **구매발주** — 계획서의 통합 지정·거래처 그룹에 뜨는 분류별(가공품·판금품·주식회사 오텍) 거래처 후보를 관리하는 화면이 생겼습니다(구매팀 › 통합 지정 거래처). 거래처 카탈로그를 검색해 추가하고, 삭제와 기본 거래처 지정이 됩니다 — 기본으로 표시한 거래처가 계획서 첫 진입값입니다.
- **구매발주** — 모듈 풀에서 선택한 모듈을 **기존 발주에 추가**할 수 있습니다. 패턴에 안 걸린 모듈을 새 발주로만 묶을 수 있던 것을, 발주 목록에서 골라 바로 합칠 수 있게 했습니다(구매사유는 그대로 유지).
- **구매발주** — 실행 전 프로젝트 선택에 **최근** 목록이 생겼습니다. 실행한 프로젝트가 이 기기(브라우저)에 최대 5개까지 남아 다시 고르기 쉽습니다.
- **세금계산서** — 디버깅 중 만든 세금계산서 전표를 조회해 선택 삭제하는 테스트 문서 정리가 다른 에이전트와 같은 방식으로 생겼습니다.

### 개선

- **구매발주** — 계획서 화면을 정리했습니다. 각 발주단위가 파란 타이틀 밴드와 왼쪽 라인으로 뚜렷하게 구분되고, 세 구획(통합 지정 → 모듈 풀 → 발주단위)은 여백으로 나뉩니다. 계획서가 열리면 상단에 이 개입이 무엇을 요청하는지(계획 확정까지만 진행, ERP 저장 없음) 안내가 항상 표시됩니다. 통합 지정의 날짜·거래처 입력이 같은 크기로 통일됐고, [전체 계획서 검토] 버튼은 요약·미충족 사유와 함께 화면 하단에 고정되어 스크롤 없이 누를 수 있습니다. 발주단위의 구매사유·납기예정일 줄이 틀어지던 것도 정렬했습니다.
- **공통** — 에이전트 동시 실행 상한이 2개에서 30개로 늘었습니다. 여러 계정이 같은 시간에 실행해도 대기 없이 진행됩니다(서버 사양 범위 내).
- **구매발주** — 발주 패턴 관리의 되돌리기·저장 버튼이 화면 하단에 고정되고, 저장하지 않은 변경이 있는지 버튼 옆에 표시됩니다.
- **세금계산서** — 발행 전 화면의 거래처를 거래처 카탈로그에서 검색해 선택합니다. ERP 등록은 거래처명이 정확히 일치해야 해서, 직접 입력 대신 실명 선택으로 바꿨습니다. 예산단위·적요처럼 긴 이름이 입력 칸을 밀어내던 것도 고쳤습니다.

### 수정

- **세금계산서** — 증빙을 적용한 직후 뜨는 계산서 목록 팝업을 알 수 없는 창으로 오인해 실행을 중단하던 문제를 고쳤습니다.
