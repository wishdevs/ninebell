### 변경

- **법인카드** — 저장이 거부되면 자동으로 재시도하지 않습니다. 실패 사유를 채팅으로 알려주고, 그대로 재저장("저장해줘")·건별 입력 화면에서 수정("다시 시도")·종료 중에서 선택하게 바뀌었습니다.

### 추가

- **법인카드** — 저장이 "업무용차량 미입력"으로 거부되면 대상 내역과 법인 차량 목록을 채팅에 표로 보여줍니다. 채팅으로 차량을 고르면(전체 같은 차량은 '3번', 내역별로 다르게는 '1-1, 2-3') 자동으로 입력하고 다시 저장까지 진행합니다.

### 개선

- **공통** — 로그인 후 메뉴 진입이 11.8초에서 8.6초로 빨라졌습니다.
- **법인카드** — 채팅으로 조치하는 동안에도 실행 화면이 크게 유지되고, 처리 현황은 긴 표 대신 한 줄 요약으로 표시됩니다. 새 메시지가 오면 채팅이 자동으로 아래로 내려갑니다.

### 주요 수정

- **법인카드** — 본인 카드가 있어도 카드번호가 전체선택되던 문제를 고쳤습니다. 카드명 괄호 속 이름과 대조해 본인 카드만 선택합니다.
- **법인카드** — 저장(F7)이 화면 하단 경고(관리항목 미입력 등)로 거부됐는데도 완료로 표시되던 문제를 고쳤습니다. 저장 후 재조회로 실제 저장 여부까지 확인합니다.
- **법인카드** — 승인번호가 00000000이거나 거래처가 빈 내역이 전표에 포함될 수 있던 문제를 고쳤습니다. 이제 조회 단계에서 자동으로 제외하고 제외 건수를 알려줍니다.

### 보안·개인정보

- **공통** — 운영 로그에 남던 자격증명(비밀번호 등)을 마스킹합니다.
