### 추가

- **에이전트 그룹 접근관리** — 에이전트 접근 화면이 그룹 단위로 확장됐습니다. 그룹 접근권한과 그룹 내 에이전트 접근권한을 각각 지정할 수 있고, 사용자는 **둘 다** 허용된 경우에만 해당 에이전트를 보고 실행할 수 있습니다(미설정 그룹은 종전처럼 전체 허용, 관리자는 제한 없음).

### 변경

- **직접 입력 제거** — 구매발주 프로젝트 선택과 통합 지정 거래처에서 "카탈로그에 없나요? 직접 입력" 기능을 없앴습니다. 모든 기준 데이터는 ERP 가 우선이며, 목록에 없는 항목은 ERP 에 등록한 뒤 카탈로그 동기화로 반영합니다.
