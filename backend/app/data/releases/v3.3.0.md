### 추가

- **유형별 전표조회 승인** — 전표유형을 실측 전체 62종에서 이름이나 코드로 검색해 선택할 수 있습니다. 프리셋(외상매출금·외상매입금)과 선택 칩은 그대로이고, 휴대폰에서는 아래에서 올라오는 선택 시트로 열립니다.
- **유형별 전표조회 승인** — 전자결재 상신 시 결재라인에 지정된 상대 계정이 자동으로 추가됩니다.
- **공통** — 각 그룹 화면 오른쪽 위에서 그 그룹의 기준정보와 에이전트 설정을 바로 엽니다. 결의서입력은 예산단위·프로젝트·거래처 관리와 법인카드·출장(국내/자차) 설정, 회계전표는 유형별 전표조회 승인 설정, 구매팀은 프로젝트 관리와 발주 패턴입니다.
- **공통** — 자주쓰는 프로젝트를 결의서용과 구매팀용으로 따로 관리합니다. 프로젝트 목록 자체는 공유되고(동기화 시 동일), 자주쓰는 지정과 기본 지정만 용도별로 분리됩니다.

### 개선

- **구매발주** — '1주 전' 납기 계산이 영업일 5일 기준으로 정확해졌습니다. 공휴일·주말이 끼면 그만큼 앞으로 이동해 영업일을 보존하고, 연동된 파생 납기도 함께 움직입니다. 공휴일 데이터가 월력요항 기반으로 교체되어 대체공휴일·임시공휴일·노동절·제헌절까지 반영됩니다.

### 변경

- **유형별 전표조회 승인** — 메뉴 필터 항목의 추가·삭제가 실행 전 폼에서 에이전트 관리(관리자)로 옮겨졌습니다. 실행 전 폼에서는 선택만 합니다.
- **공통** — 에이전트 관리 화면이 그룹 폴더 없이, 설정을 가진 에이전트의 목록으로 바뀌었습니다. 항목을 열어 편집하고, 그룹 화면의 설정 버튼으로도 같은 곳에 진입합니다.

### 수정

- **유형별 전표조회 승인** — 실행 전 폼의 입력 폭을 결의서 계열과 같은 가독 폭으로 제한했습니다.
- **구매발주** — 구매사유·비고의 프로젝트 표기에서 코드를 빼고 프로젝트명만 남겼습니다.
