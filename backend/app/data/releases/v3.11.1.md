### 주요 수정

- **구매발주** — 발주 저장 중 변경거래처 적용이 전부 미반영으로 끝나 발주가 실패하던 문제 — 구매요청 팝업 조회 직후 늦게 도착한 재조회로 그리드가 바뀌면 행 번호가 어긋나던 원인이었습니다. 이제 행을 번호가 아니라 요청번호·품목으로 다시 찾아 적용·확인하고, 미반영 시 행을 다시 체크한 뒤 재적용합니다.
- **구매발주** — 상신·발주에서 일부 건이 혼선·타이밍으로 실패해도 실행이 중단되지 않습니다. 병렬 1차 뒤 실패 건만 다시 시도하며, 실패가 많으면 병렬로, 적으면 하나씩 순서대로 처리합니다(최대 3차). 진짜 오류만 마지막에 실패로 표시됩니다.

### 수정

- **메뉴얼** — 구매발주 매뉴얼을 실제 화면 캡처와 예제 위주로 다시 썼고, 발주 패턴 관리는 별도 문서로 분리했습니다. 구매발주 화면과 발주 패턴 관리 화면에서 바로 열 수 있습니다.
- **구매발주** — 실행 완료 안내가 "구매발주 저장은 직접 진행"이라는 낡은 문구를 보여주던 문제를 현재 동작(발주 저장까지 자동)에 맞게 고쳤습니다.
