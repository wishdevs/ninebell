## 국내·자차와 다른 점

| | 국내·자차 | 해외·정산서 |
|---|---|---|
| 행 종류 | 통행료 / 유류비 구분 | 구분 없음 — 전 행 동일 |
| 거래처 | 통행료는 카탈로그, 유류비는 본인 | 전 행 작성자 본인 |
| 예산단위 | 여비교통비-국내출장 | 여비교통비-해외출장 |
| 금액 항목 | 거래금액 | 공급가액 |

나머지는 같다. 증빙유형 10 을 행마다 다시 고르는 것, 금액을 타이핑하는 것,
마스터 합계를 직접 세팅하는 것, 상대계정 등록 후 빈 행을 지우는 것 모두 동일하다.

## 미확인을 다루는 방식

이 에이전트는 행별로 **어느 필드를 확인하지 못했는지 이름까지 모아 둔다.**
하나라도 있으면 마지막 로그를 '완료' 라고 쓰지 않고 미확인 목록을 함께 남긴다.
반영을 단정하는 로그가 미확인 값을 덮으면 저장 결과를 역추적할 근거가 사라지기 때문이다.

## 상신 주의

월이 걸친 출장은 결의서를 나눠 상신해야 한다. 상신은 이 에이전트가 하지 않는다.
