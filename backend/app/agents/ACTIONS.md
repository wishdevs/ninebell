# 에이전트 행위 표기법 — 단일 소스

에이전트가 화면·파일·메일에 하는 모든 행위를 **정해진 낱말**로만 적는다. 산문으로 적으면
같은 동작이 문서마다 다른 말로 남고, 무엇이 되돌릴 수 없는 행위인지가 묻힌다.

각 에이전트의 실제 표기는 `<에이전트>/FLOW.md` 에 있다(맨 아래 색인).
왜 그렇게 하는지·실측 근거·사고 이력은 기존 `PROCESS.md` 가 계속 담는다. 둘은 짝이다.

- `FLOW.md` — **무엇을 어떤 순서로 하는가**(이 표기법)
- `PROCESS.md` — **왜 그렇게 하는가**(실측·근거·함정)

---

## 한 줄 읽는 법

```
변경  [값설정]    결의구분: 카드        확인 드롭다운=카드   정착후  중단
────  ────────    ─────────────        ──────────────────  ──────  ────
등급   동사        대상: 값              사후 확인            시점    실패 처리
```

등급은 줄 맨 앞에 두 글자로 정렬한다. 세로로 훑기만 해도 **되돌릴 수 없는 줄**이 어디인지
보이는 것이 이 배치의 목적이다.

---

## 부작용 등급 (6)

| 표기 | 뜻 |
|---|---|
| `읽기` | 화면·파일을 바꾸지 않는다 |
| `변경` | 바뀌지만 되돌릴 수 있다 (문서 미확정) |
| `확정` | 되돌릴 수 없다 — `승인필요` 없이 실행 금지 |
| `발신` | 회사 밖으로 나가 회수 불가 (메일) |
| `대기` | 외부 사건을 기다린다 — 세션을 끝내고 나중에 재개 |
| `금지` | 자동화가 실행하지 않는다 |

## 수식어 (6)

| 표기 | 뜻 |
|---|---|
| `확인 대상=기댓값` | 실행 후 다시 읽어 대조한다 |
| `즉시` / `정착후` | 언제 읽을지 — 셀은 즉시, 화면 재구성을 부르는 값은 정착 후 |
| `중단` / `경고` | 어긋났을 때 끊을지, 기록만 남기고 갈지 |
| `재시도N` | 최대 N회 |
| `승인필요` | 사용자 승인 게이트 |
| `미검증` | 라이브 확인 전 가설 |

`중단`과 `경고`의 갈림은 규율이 있다. **값이 다르면 중단, 읽지 못하면 경고**다.
리더가 화면을 못 읽는 것은 오탐일 수 있어, 멀쩡한 실행을 끊는 근거로 쓰지 않는다.
다만 조용히 넘기지도 않는다 — 확인하지 못한 채 지나갔다는 사실이 로그에 남아야
나중에 "완료로 보이는데 값이 안 붙은" 결과를 되짚을 수 있다.

## 제어 구조 (3) — 들여쓰기로 표현

```
반복  전표마다
        변경  [행선택]  이 전표

분기  0건이면        기록만 남기고 다음으로
      1건이면
              변경  [행선택]  첫 행
      2건 이상이면   대상 특정 불가 — 선택하지 않고 진행

되감기  저장 실패이고 재시도가 남았으면  →  메뉴이동부터 다시
```

`[값설정]`과 `[직접입력]`을 나눈 이유가 있다. 금액을 값 주입으로 넣으면 예산현황 확인이
발화하지 않아 파생 상태가 미완인 채 저장이 거부된다. 타이핑해야만 하는 자리는
표기에서부터 다른 동사여야 한다.

`[코드선택]`을 한 동사로 묶은 이유도 같다. 열기·검색·선택·적용·닫힘확인을 따로 적으면
**닫힘 확인을 빠뜨린다**. 그 자리가 실제로 이전 행의 잔여 팝업에 값이 쓰이는 사고를 냈다.

### 확정 (6)

| 동사 | 하는 일 | 등급 |
|---|---|---|
| `[저장]` | 저장(F7) — 번호 확정 | 확정 |
| `[상신]` | 전자결재 상신 | 확정(전표조회승인 계열) / 금지(그 외) |
| `[승인]` | 결재 승인 | 확정 |
| `[결재취소]` | 상신문서의 결재를 취소 — 문서가 미결문서로 내려온다 | 확정 |
| `[상신취소]` | 미결문서의 상신을 취소 — 문서가 임시보관문서로 내려온다 | 확정 |
| `[문서삭제]` | 임시보관문서 삭제 — 문서가 사라진다 | 확정 |

취소 3형제(`[결재취소]`·`[상신취소]`·`[문서삭제]`)는 `[행삭제]`(F6, 그리드 행)와 다르다.
대상이 **문서 한 장 전체**이고, 셋 다 되돌릴 수 없다. `eap_cancel` 만 쓰며, 사용자가 목록에서
체크한 문서에만 실행한다.

`[상신]`은 에이전트 계열에 따라 등급이 갈리는 유일한 동사다. **전표조회승인 계열
3종**(외상매출금·외상매입금·미지급금 법인카드)만 `확정 … 승인필요` 로 실행하고
(사용자 승인 2026-08-07 — EAP 결재취소로 회수 가능해진 것이 근거, `allow_submit` 게이트),
**결의서입력 계열을 포함한 그 외 모든 에이전트는 `금지` 그대로**다. 다른 FLOW.md 에
`확정 [상신]` 을 새로 적으려면 여기 표부터 고친다.

## 유지 규칙

1. 그래프 노드가 바뀌면 해당 `FLOW.md` 를 같은 커밋에서 고친다.
2. 새 동사가 필요하면 **여기 먼저** 등록하고 쓴다. 등급을 반드시 정한다.
3. `확정`·`발신` 등급 줄에는 `승인필요` 가 붙어야 한다. 예외는 없다.
4. 라이브로 확인하지 않은 줄에는 `미검증` 을 남긴다. 확인되면 지운다.
